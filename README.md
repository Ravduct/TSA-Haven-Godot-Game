# Jelly Journey

You are on a late night walk with your dog. While you look away, a UFO flies past and kidnaps your dog. You must return a scepter to the alien so he can release your dog, but the scepter is on an alien planet made of very bouncy jell-O.

## What Would You Do?

This game is about releasing your beloved pet dog from a mysterious alien.

## Purpose of This Game:

This is the game we made in Haven Hackclub (one of the large scale hackathon for teenagers) With just 24 hours.

## Extra Notes

This game is in beta. Many features are not added, and bugs are likely. if you find bugs, please let us know so we can fix them as we update our game.
